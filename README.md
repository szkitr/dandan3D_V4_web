# dandan3D ブラウザ版

修士研究のゲーム dandan3D を、ブラウザで遊ぶためのページです。ここには書き出したファイルだけを置いています(ソースは非公開)。版はここには書きません(ゲームの最初の画面の下に出ます)。

- 開く:https://szkitr.github.io/dandan3D_web/
- 運営の PC で運営のアプリが部屋を開いているあいだ、このページを開いて画面を一度押すと、部屋と声に入ります。合言葉や参加コードは要りません。**このアドレスを知っている人は、誰でも入れます。**
- アドレスに `?room=` を付けなければ、決まった部屋 `dandan-web` に入ります。合言葉ではありません(秘密にしていません)。
- マイクは、はじめの機器選択で準備します(ブラウザのマイク使用許可が必要です)。声は役の声に変えてから、通話(Unity Vivox)に送ります。記録に同意した人の声は、運営の PC で録音します。このブラウザの中には、声をファイルや保存領域に残しません。カメラ・映像・顔の特徴点は使いません。
- 軽くするため、画面の細かさを下げています。
- 2026-11-04 に、リポジトリの名前を `dandan3D_V4_web` から `dandan3D_web` に変えました。古いアドレス(https://szkitr.github.io/dandan3D_V4_web/)は開けなくなりました(新しいアドレスへの案内もありません)。
