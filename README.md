# dandan3D ブラウザ版の試し(web spike)

修士研究のゲーム dandan3D の、ブラウザで参加する仕組みの試しです(2026-11-03)。はじめは V4 から、同じ日の夜から V5 から書き出しています(いまは 5.1)。

- 開く:https://szkitr.github.io/dandan3D_V4_web/
- 置きっぱなしの運営(5.1 から)の部屋に入るには、運営から配られる専用のリンクが要ります。リンクを開いて画面を一度押すと、部屋と声に入ります。このページをリンクなしで開いても、その部屋には入れません。
- 手動の運営の部屋には、今まで通り、運営が出す参加コードを打って入ります。
- 声は通話(Unity Vivox)にだけ送ります。ブラウザの中でファイルや保存領域に残しません。映像・顔の特徴点は使いません。
- 5.0 から、マイクの処理(echo cancel / noise suppress / auto gain)を入り切りして、音質を聞き比べられます(「7. Microphone」)。
- このリポジトリには書き出したファイルだけを置いています(ソースは非公開)。
